# skill-ops — QA：踩過的坑與設計理由

> 給要改這支、或想懂「為什麼長這樣」的人。每一條都是實戰換來的，不是原則清單。

## Q1 為什麼把三支 skill 合併成一支？

前身是三支（建skill／挖候選／巡檢）。實測發現三條分軸只剩一條半成立：對象顆粒（還沒有／一支／全部）是真的；「觸發源不同」不成立——排程那支從第一天就沒掛上任何排程；「質性 vs 量性」也不成立——audit 當天跑的就是整套量化指標。合併後 always-on description 從 1535 字元降到 737、routing 稅省 52%，而且解決了真正的病：**使用者不知道該叫哪支**。

## Q2 為什麼巡檢（§5）要配一個 SessionStart hook？

前身那支巡檢 SOP 上線兩個月、全機 transcript **0 次顯式呼叫**。不是沒用，是沒有東西會主動叫它——**排程型 SOP 沒有主動面就等於不存在**。hook 刻意只提醒、不自動跑：它讀一個日期檔、報一個天數，指標仍是人（或 agent 被人叫了）手動跑。主動面與拍板權分開。

## Q3 為什麼產出一律硬停在「user 圈選」？

模型有「想做點事證明自己有用」的偏見。把 dispatch 權放給 agent，audit 會靜默變成自動改檔。所以五段的產出形狀都是 shortlist／排序表，改動權留在人手上。

## Q4 為什麼 N=2 才建、N=1 只觀察？

多數「想抽成 skill」的東西其實不該抽。skill 的真實成本在維護不在建立：每支都佔 always-on routing 空間、都會過期、都要巡。一次性需求寫一行觀察就夠。

## Q5 「入口 superset 不變式」是什麼？為什麼附一支腳本？

SKILL.md 對各 SOP 的描述只准摘要、禁止增添——出現在入口而不在本體的「方法性語句」一定會跟本體漂移。`scripts/check_entry_superset.py` 只抓可機械判定的 token（來源名／指令名），散文式改寫要人工。本 repo 出貨時實跑為 **0 違規（exit 0）**。跑出任何違規＝有東西漂了——開 issue 回報、不要自行修。

## Q6 為什麼 SKILL.md 用中文，其他隨附 skill 是英文？

擁有者拍板：LLM 對 description 做的是**跨語言語意匹配**，英文請求照樣觸發中文 description。正文語言不影響路由，影響的只是人的閱讀——所以 `human/` 的圖解做成中英單檔切換。

## Q7 「🔒 外來原樣保留」是什麼？

有些 skill 的全部價值就在「一字不改」（本 repo 的 `eli5` 整支只有一句話，照本檔的 anatomy 標準改寫它等於毀掉它）。標記寫在被保留那支自己身上、不另設豁免名單——名單會跟本檔漂開。**加標記本身需 user 拍板**：否則整份 anatomy 標準可以被任何 agent 用一行字關掉。

## Q8 為什麼 audit 的 4 Tier 必須依序、不可跳？

Tier 1（格式對照）最便宜，跳過它直接看使用證據會漏掉結構病。另一個實戰坑：用 grep 判合規時，**命中的那行要先分清是「在規定」還是「在做」**——規則自己引用違規字樣是常態，把規定那行當違規證據是重複踩過的錯。

## Q9 為什麼「改完既有 skill」要強制跑 8 步 closing protocol？

多次實測「retrofit 聲明 ≠ 實際」：自稱完成，但 PII 沒掃、sibling 的引用沒同步、觸發詞跟別支打架。而且**自跑 dogfood 只能查機械面**（grep 得到的），語義面的漏（摘要層與詳細層改一邊漏一邊）要獨立 agent 才抓得到——兩個都要跑。

## Q10 什麼是「冷讀者測試」？為什麼 body 不准寫演化史？

「原本是 X、後來降為 Y、回收先前的 Z」這種系譜語法，是寫給經歷過那段歷史的人看的；第一次讀的人只需要現況。演化史屬於 changelog（本公開版不隨附）、body 一律直述現況。anatomy 有一格專抓這個——而且要指定「第一次讀的視角」才有效，作者自查會把系譜語法當成必要存在。

## Q11 為什麼觸發詞「寧多勿刪」、還要有獨佔宣告？

上下游 skill 共用觸發詞會互相劫持（hijack）：使用者說一句話、跑錯支、而且是靜默跑錯。獨佔宣告＝明文「這幾個詞歸我」，瘦身 pass 不得刪。

## Q12 `human/` 那兩張圖是怎麼來的？

用本 repo 隨附的 `eli5` 與 `explain1min` 兩支 skill，對 skill-ops 自己跑出來的（dogfood）。單檔內建中英切換、深淺色雙主題。改了 SKILL.md 的路由結構，記得回來同步這兩張圖——圖與本體矛盾比沒有圖更糟。
